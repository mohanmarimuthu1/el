## Getting Started Locally

If you would like to spin this up locally and look under the hood, here is how you can do it in a few steps:

### 1. Clone the repository

git clone [https://github.com/mohanmarimuthu1/el.git](https://github.com/mohanmarimuthu1/el.git)
cd el
2. Set up dependencies
For Python:

Bash
pip install -r requirements.txt
For Node.js:

Bash
npm install
3. Configure Environment Variables
Create a .env file in the root directory and add any required keys or configurations based on the environment template.

4. Run the Prototype
Python:

Bash
python main.py
Node.js:

Bash
npm run dev
